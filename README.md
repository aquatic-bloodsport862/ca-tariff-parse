## 🛠️ About the Technology

This tool is built with a concept called **“deterministic parsing.”** That means given the same PDF input, it always produces the same output. There’s no guessing, no artificial intelligence, no “best guess” interpretation. If the PDF says a rate is $0.35 per kilowatt-hour, that’s what the tool says—with proof.

The emphasis on **data-provenance** (knowing where every number came from) makes this tool particularly valuable for regulators, researchers, journalists, and advocates who need to hold utilities accountable with verifiable facts.

Because it’s **fail-closed**, if it encounters a situation it doesn’t understand, it stops and tells you rather than producing a potentially wrong answer. This is by design—correct data matters more than complete data.
